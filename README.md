## ▓▒░ About ░▒▓

A terminal-dweller who speaks more fluently to machines than to humans.  
Writing **C** and **Assembly** because abstraction is for those afraid of reality.

> *"The world has already ended. Yet we keep walking."*

<br/>

- 🔭 Building an experimental **cryptographic hash function** in `XzalgoChain` (SIMD AVX2/NEON)
- ⚙️ Crafting a **multithreaded HTTP server** in `xzrahttp`
- 🧹 Writing a **Zsh history deduplication** utility in `zclean`
- 🌱 Always learning: **low-level systems, cryptography, SIMD**
